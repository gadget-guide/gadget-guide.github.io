11. 무인 자동 실행 (고급)

실행 파일을 --auto 옵션과 함께 실행하면, 창이 뜨자마자 사람이 아무것도 누르지 않아도 자동으로 매크로를 시작합니다(등록해둔 계정과 체크해둔 카테고리/미션/옵션을 그대로 사용). 이걸 Windows 작업 스케줄러에 등록해두면 정해진 시간에 PC가 알아서 실행하게 만들 수 있습니다.

옵션 뒤에 번호를 붙여 실행할 기능을 고릅니다

인수실행되는 기능
--auto브랜드평판 → 유튜브 (번호를 안 붙였을 때의 기본값)
--auto 1브랜드평판만
--auto 2유튜브만
--auto 3스타플래닛만
--auto 4셀럽챔프만
--auto 3,4스타플래닛 → 셀럽챔프 (적은 순서대로 하나씩)
  • 쉼표로 여러 번호를 이으면 적은 순서대로 하나가 끝난 뒤 다음을 시작합니다(v2.1.0부터). --auto 4,3이면 셀럽챔프를 먼저 합니다. 쉼표 앞뒤에 띄어쓰기를 넣지 마세요.
  • 스타플래닛과 셀럽챔프는 v2.0.8부터 자동 실행에 포함됩니다. 휴대폰이 USB로 연결되어 있어야 합니다.
  • 재생목록은 자동 실행 대상이 아닙니다.
  • 1~4가 아닌 값을 넣으면 번호를 안 붙인 것으로 보고 브랜드평판 → 유튜브를 실행합니다.
  • 모두 끝나면 로그창 맨 아래에 기능별 결과를 합친 전체 요약이 한 번 더 찍힙니다.
먼저 확인 실행이 끝나도 창이 저절로 닫히지는 않습니다 — 로그에 결과가 남은 채로 계속 떠 있습니다. 브랜드평판과 유튜브를 같은 시간에 따로 돌리고 싶다면 작업을 두 개 만들어 각각 --auto 1, --auto 2로 등록하면 됩니다. 휴대폰을 쓰는 3번과 4번은 휴대폰이 한 대이므로 동시에 돌리지 말고 --auto 3,4처럼 이어서 실행하세요.

자동 실행 중의 업데이트

새 버전이 나와 있으면 --auto 실행에서는 묻지 않고 바로 업데이트한 뒤, 같은 옵션으로 프로그램을 다시 실행해 이어서 진행합니다. 사람이 없는 시간에 업데이트 창에서 멈춰 있는 일이 없도록 한 동작입니다.

준비: 실행 암호를 먼저 한 번 저장해두기

이 프로그램은 실행할 때마다 실행 암호를 확인합니다. 사람이 없는 새벽 시간에 스케줄이 돌면 그 암호창을 눌러줄 사람이 없어 그대로 멈춰버립니다. 다행히 한 번 암호를 맞게 입력해두면 같은 PC에서는 관리자가 암호를 바꾸기 전까지 다시 묻지 않으므로, 스케줄을 등록하기 전에 그 PC에서 프로그램을 한 번 직접 실행해서 암호를 통과시켜두세요. 이후 무인 실행부터는 암호창 없이 바로 진행됩니다.

Windows 작업 스케줄러 등록하기

  1. 작업 스케줄러를 엽니다
    Windows 검색(또는 Win + R)에서 taskschd.msc를 입력하고 실행합니다.
  2. 오른쪽 "작업 만들기"를 클릭합니다
    ("기본 작업 만들기"보다 세부 설정이 가능한 작업 만들기를 추천합니다.)
  3. 일반 탭 — 이름을 정하고, "사용자가 로그온했는지 여부에 관계없이 실행"을 고를지 정합니다
    로그온 여부와 무관하게 실행하도록 하면 화면이 안 보이는 상태(잠금 화면 등)에서도 돌아가지만, 진행 상황을 눈으로 확인하기는 더 어렵습니다. 처음 설정할 때는 "로그온한 경우에만 실행"으로 두고 화면을 보면서 한 번 테스트해보길 권합니다.
  4. 트리거 탭 — "새로 만들기"로 원하는 시작 시간을 지정합니다
    예: 매일 오전 6시.
  5. 동작 탭 — "새로 만들기" → "프로그램 시작"을 고릅니다
    프로그램/스크립트에는 실행 파일의 전체 경로(예: D:\매크로 폴더 안의 exe 파일)를, 인수 추가에는 --auto(또는 --auto 3,4처럼 원하는 번호)를 입력합니다. 시작 위치(옵션)에는 실행 파일이 들어 있는 폴더 경로를 넣어 두세요.
  6. 저장하고, 등록한 작업을 오른쪽 클릭 → "실행"으로 한 번 테스트합니다
    프로그램이 정말 자동으로 고른 기능부터 시작하는지, 로그창에 진행 상황이 잘 찍히는지 확인하세요.

절전 모드, 화면 잠금, 휴대폰 화면 꺼짐처럼 무인 실행에서 자주 걸리는 부분은 매일 자동으로 돌릴 때 준비에 따로 정리했습니다.
