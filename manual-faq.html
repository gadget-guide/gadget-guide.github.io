13. 문제 해결 / FAQ

설치와 실행

실행 암호가 틀렸다고 나옵니다
암호는 주기적으로 바뀔 수 있습니다. 관리자에게 최신 암호를 다시 확인해주세요. 3번 틀리면 프로그램이 종료되니, 정확한 암호를 확인한 뒤 다시 실행해주세요.
"인증 서버 연결 실패"가 뜹니다
실행 암호를 확인하는 과정에서 인터넷 연결이 필요합니다. Wi-Fi/네트워크 연결 상태를 확인한 뒤 창의 "다시 시도" 버튼을 눌러주세요. 회사나 학교 네트워크처럼 구글 서비스 접속이 막힌 곳에서는 통과하지 못할 수 있습니다.
어제까지 되던 암호를 갑자기 다시 묻습니다
관리자가 암호를 바꾼 것입니다. 한 번 통과한 PC도 암호가 바뀌면 그 즉시 다시 확인합니다.
"Windows의 PC 보호" 창이 뜹니다
"추가 정보"를 누르면 나타나는 "실행" 버튼으로 진행합니다. 자세한 내용은 2장에 있습니다.
업데이트 창이 뜨지 않습니다
이미 최신 버전이거나, 자동 업데이트가 없는 v1.9.14 이하 버전입니다. 창 제목의 버전 번호를 업데이트 내역의 최신 버전과 비교해 보세요.
"업데이트 실패"가 뜹니다
새 버전을 받는 도중 인터넷이 끊겼을 때 나옵니다. 프로그램은 지금 버전으로 그대로 쓸 수 있고, 다음에 실행할 때 다시 업데이트를 안내합니다.

휴대폰 연결

"연결된 안드로이드 기기가 없습니다"라고 나옵니다
가장 흔한 원인은 케이블입니다. 데이터 전송이 되는 케이블인지 다시 확인하고, 다른 USB 포트(가능하면 PC 본체 뒷면 포트)에도 꽂아보세요. 그래도 안 되면 휴대폰 화면을 켜고 잠금을 해제한 상태로 다시 연결해보세요. 단계별 점검은 휴대폰 연결이 안 될 때에 있습니다.
"휴대폰에서 USB 디버깅을 허용해주세요"라고 나옵니다
PC는 휴대폰을 찾았지만 휴대폰에서 아직 허용하지 않은 상태입니다. 휴대폰 화면을 켜면 "USB 디버깅을 허용하시겠습니까?" 팝업이 떠 있을 것입니다. "이 컴퓨터에서 항상 허용"을 체크하고 허용을 누르세요.
"USB 디버깅 허용" 팝업이 매번 다시 뜹니다
팝업이 뜰 때 "이 컴퓨터에서 항상 허용" 체크박스를 켜지 않으면 매번 다시 물어봅니다. 다음에 뜰 때 꼭 체크해주세요.
휴대폰을 두 대 연결해도 되나요
한 번에 한 대만 연결해 주세요. 여러 대가 연결되어 있으면 먼저 인식된 한 대만 사용합니다.
휴대폰에 화면 잠금(PIN, 패턴)이 걸려 있습니다
프로그램은 꺼진 화면을 켜고 밀어서 잠금을 푸는 것까지만 할 수 있습니다. PIN이나 패턴, 지문은 대신 풀 수 없으니, 실행 전에 직접 잠금을 풀어 두거나 무인 실행용 휴대폰은 잠금을 "드래그"로 바꿔 두세요.

실행 중

미션을 하다가 중간에 멈췄어요
하단 로그창에 남은 마지막 몇 줄을 그대로 캡처해서 문의해주시면 원인을 빠르게 확인할 수 있습니다. 광고가 예상과 다르게 뜨는 경우 자동으로 복구를 시도하지만, 드물게 복구가 안 되는 광고 유형이 있을 수 있습니다.
"시작"을 눌러도 시작되지 않습니다
다른 탭의 기능이 이미 실행 중이면 시작되지 않습니다. 실행 중인 기능이 끝나거나 "정지"를 누른 뒤 다시 시작하세요. "사용"을 체크한 계정이 하나도 없을 때도 시작되지 않습니다.
브랜드평판이 시작하자마자 끝납니다
오늘 한도를 이미 채운 계정이면 곧바로 한도 초과로 끝납니다. 로그의 결과 요약에서 계정별 사유를 확인하세요.
유튜브 로그인 화면에서 멈춰 있습니다
구글이 2단계 인증을 요구하는 중입니다. 열린 크롬 창에서 직접 인증을 마치면 이어서 진행합니다 (최대 10분 대기).
셀럽챔프 쿠팡 룰렛을 했는데 장미가 안 올랐습니다
v2.1.4에서 페이지가 늦게 열리는 휴대폰에서 적립이 빠지던 문제를 고쳤습니다. 최신 버전으로 업데이트해 주세요. 같은 날 이미 참여했다면 다시 적립되지 않습니다.
실행 중에 PC나 휴대폰을 써도 되나요
PC에서 다른 작업을 하는 것은 괜찮습니다. 다만 프로그램이 띄운 크롬 창과 연결된 휴대폰은 건드리지 마세요.

기록과 문의

로그 파일은 어디서 보나요
실행 폴더 안 logs 폴더에 날짜별(20261013.log 형식)로 저장됩니다. 화면의 로그창과 같은 내용이 그대로 파일로도 남습니다. 같은 날 여러 번 실행하면 _2, _3이 붙은 파일이 따로 생깁니다.
문의할 때 무엇을 보내야 하나요
창 제목에 보이는 버전 번호, 어떤 탭에서 무엇을 하다가 생긴 문제인지, 그리고 해당 날짜의 로그 파일을 보내 주세요. 휴대폰 앱 기능이라면 휴대폰 기종도 알려 주세요.
계정과 설정을 다른 PC로 옮기고 싶습니다
%APPDATA% 아래의 프로그램 설정 폴더를 새 PC의 같은 위치에 복사하면 됩니다. 실행 암호는 새 PC에서 한 번 다시 입력해야 합니다.
