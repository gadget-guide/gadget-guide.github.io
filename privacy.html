사이트

개인정보처리방침

시행일: 2026년 10월 13일

이 문서는 매크로 사용 설명서 사이트(이하 "사이트")와 매크로 프로그램(이하 "프로그램")이 어떤 정보를 다루는지 설명합니다.

1. 사이트가 수집하는 정보

사이트에는 회원가입, 로그인, 댓글, 문의 양식이 없습니다. 운영자가 방문자의 이름, 이메일, 전화번호 같은 개인정보를 직접 수집하거나 보관하지 않습니다.

사이트는 GitHub Pages로 제공됩니다. 페이지를 열 때 방문자의 IP 주소와 브라우저 정보가 호스팅 회사의 서버 기록에 남을 수 있으며, 이 기록은 GitHub의 개인정보 처리 방침에 따라 관리됩니다. 운영자는 이 기록을 열람하지 못합니다.

2. 광고와 쿠키

사이트에는 Google 애드센스 광고가 게재될 수 있습니다.

  • Google을 포함한 제3자 광고 사업자는 쿠키를 사용해, 방문자가 이 사이트나 다른 웹사이트를 방문한 기록을 바탕으로 광고를 게재합니다.
  • Google은 광고 쿠키를 사용해 방문자가 이 사이트와 인터넷의 다른 사이트를 방문한 정보를 바탕으로 Google과 그 파트너가 맞춤 광고를 보여 줄 수 있게 합니다.
  • 맞춤 광고를 원하지 않으면 Google 광고 설정에서 끌 수 있습니다. 다른 광고 사업자의 맞춤 광고 쿠키는 aboutads.info에서 거부할 수 있습니다.
  • Google이 광고와 관련해 정보를 어떻게 사용하는지는 Google 서비스를 사용하는 사이트에서 Google이 정보를 사용하는 방법에서 확인할 수 있습니다.
  • 브라우저 설정에서 쿠키 저장을 막거나 지울 수 있습니다. 쿠키를 막아도 사이트의 모든 내용을 볼 수 있습니다.

3. 프로그램이 다루는 정보

PC에만 저장되는 정보

  • 등록한 계정의 아이디와 비밀번호, 체크한 카테고리와 옵션, 재생목록의 영상 목록은 사용하는 PC의 Windows 사용자 폴더(%APPDATA% 아래의 프로그램 설정 폴더)에 저장됩니다. 계정 정보는 해당 서비스에 로그인할 때만 사용되며 운영자나 다른 서버로 전송되지 않습니다.
  • 실행 기록(로그)은 프로그램 폴더의 logs 폴더에 저장됩니다. 문의하면서 직접 보내 주시는 경우가 아니면 운영자에게 전달되지 않습니다.
  • 실행 암호는 평문으로 저장하지 않고, 맞게 입력했다는 확인 값만 PC에 남깁니다.

프로그램이 인터넷으로 주고받는 정보

  • 실행 암호 확인 — 현재 암호가 무엇인지 확인하기 위해 관리자가 관리하는 문서를 읽어 옵니다. 사용자의 정보는 보내지 않습니다.
  • 업데이트 확인 — 새 버전이 있는지 확인하고 파일을 내려받습니다. 사용자의 정보는 보내지 않습니다.
  • 키워드 정답 공유 — 스타플래닛의 쇼핑·플레이스 미션에서 찾은 문제와 정답, 상품 사진을 공유 저장소에 올리고 내려받습니다. 계정 정보는 포함하지 않습니다.
  • 쿠팡 파트너스 배너 — 프로그램 화면의 배너는 쿠팡이 제공하며, 배너를 불러오는 과정에서 쿠팡의 정책에 따라 쿠키가 사용될 수 있습니다.

위에 적은 통신 과정에서도 일반적인 인터넷 접속과 마찬가지로 IP 주소가 각 서비스 제공자의 서버 기록에 남을 수 있습니다.

4. 정보 삭제

프로그램이 저장한 정보를 지우려면 위의 프로그램 설정 폴더와 프로그램 폴더를 삭제하면 됩니다. 휴대폰에 설치된 한글 입력용 보조 키보드 앱(ADBKeyBoard)은 휴대폰의 앱 목록에서 삭제할 수 있습니다.
