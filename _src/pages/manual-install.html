2. 설치와 첫 실행

설치 프로그램이 따로 없습니다. 압축을 풀고 실행 파일을 더블클릭하면 끝입니다.

  1. zip 파일을 받습니다
    관리자에게 전달받은 압축(zip) 파일이나 다운로드 링크로 파일을 받습니다.
  2. 압축을 풉니다
    받은 zip 파일에서 마우스 오른쪽 버튼 → "압축 풀기"(또는 "모두 추출")를 누릅니다. 압축을 풀면 매크로 폴더가 하나 생깁니다. zip 파일 안에서 바로 실행하지 말고 반드시 압축을 푼 뒤 실행하세요. 폴더는 D:\매크로처럼 찾기 쉬운 곳에 두면 나중에 작업 스케줄러에 등록할 때 편합니다.
  3. 실행 파일을 더블클릭합니다
    폴더 안의 실행 파일(.exe)을 더블클릭하면 프로그램이 시작됩니다. 실행 파일만 다른 곳으로 옮기면 동작하지 않으니, 옮길 때는 폴더째로 옮기세요.
  4. 실행 암호를 입력합니다
    가장 먼저 실행 확인 창이 뜹니다. 관리자에게 전달받은 암호를 입력하고 "확인"을 누르세요. 암호는 주기적으로 바뀔 수 있으니, 예전 암호가 안 먹히면 최신 암호를 다시 문의해주세요.
참고 한 번 맞게 입력하면 같은 PC에서는 관리자가 암호를 바꾸기 전까지 다시 묻지 않습니다. (암호가 바뀌면 그 즉시 다시 확인합니다.) 첫 확인에는 인터넷 연결이 필요하니, 실행 시 인터넷 연결 상태를 확인해주세요.

"Windows의 PC 보호" 창이 뜰 때

처음 실행할 때 파란색 "Windows의 PC 보호" 창이 뜰 수 있습니다. 인터넷에서 받은 지 얼마 안 된 실행 파일에 Windows가 띄우는 일반적인 확인 창입니다. 추가 정보를 누르면 아래쪽에 실행 버튼이 나타납니다. 백신 프로그램이 파일을 격리했다면 관리자에게 받은 파일이 맞는지 확인한 뒤 백신의 예외 목록에 매크로 폴더를 추가하세요.

자동 업데이트

v2.0.0부터는 새 버전이 나오면 프로그램이 알아서 알려 줍니다. 실행 암호를 통과한 직후 새 버전이 있습니다 창이 뜨고, 현재 버전과 새 버전, 변경 내용이 함께 표시됩니다.

  • 지금 업데이트 — 새 버전을 내려받아 설치 폴더를 교체한 뒤 프로그램을 자동으로 다시 실행합니다. 받는 동안 창을 닫지 말고 기다려 주세요.
  • 나중에 — 이번에는 건너뛰고 지금 버전으로 실행합니다. 다음에 실행할 때 다시 물어봅니다.

등록한 계정과 옵션은 설치 폴더가 아닌 Windows 사용자 폴더에 따로 저장되므로 업데이트해도 그대로 남습니다. 업데이트 확인이나 내려받기가 실패해도(인터넷이 끊긴 경우 등) 프로그램은 지금 버전으로 실행됩니다.

v1.9.14 이하를 쓰고 있다면 이 버전들에는 자동 업데이트 기능이 없습니다. 새 zip 파일을 받아 위 순서대로 한 번만 직접 설치하면 그 뒤로는 자동으로 업데이트됩니다. 버전은 창 제목과 각 탭 위쪽에서 확인할 수 있습니다.

버전별 변경 내용은 업데이트 내역에서 볼 수 있습니다.
