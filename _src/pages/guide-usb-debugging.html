제조사별 개발자 옵션·USB 디버깅 켜는 법

USB 디버깅은 PC가 USB 케이블을 통해 안드로이드 휴대폰에 명령을 보낼 수 있게 허락하는 설정입니다. 켜는 원리는 모든 안드로이드 휴대폰이 같지만 메뉴 이름과 위치가 제조사마다 달라서, 많이 쓰는 제조사별로 정리했습니다.

공통 순서

  1. 설정에서 빌드번호를 찾아 7번 연속으로 눌러 "개발자 옵션" 메뉴를 나타나게 합니다.
  2. 새로 생긴 개발자 옵션에 들어가 USB 디버깅을 켭니다.
  3. 데이터 전송용 케이블로 PC에 연결하고, 휴대폰에 뜨는 허용 팝업에서 이 컴퓨터에서 항상 허용을 체크한 뒤 허용을 누릅니다.

개발자 옵션은 숨겨져 있을 뿐 모든 안드로이드 휴대폰에 들어 있는 정식 기능입니다. 켠다고 해서 보증이 사라지거나 휴대폰이 초기화되지 않습니다.

삼성 갤럭시에서 주의할 점

USB 디버깅 스위치가 회색으로 눌리지 않을 때

최근 One UI에는 자동 차단이라는 보안 기능이 있고, 새로 산 휴대폰은 켜진 상태로 나오는 경우가 많습니다. 이 기능이 켜져 있으면 USB 케이블을 통한 명령을 막기 때문에 USB 디버깅을 켤 수 없거나, 켜도 PC에서 조작이 되지 않습니다.

  • 설정 > 보안 및 개인정보 보호 > 자동 차단에서 기능을 끄거나, 세부 항목 가운데 USB 케이블 명령 차단만 해제합니다.
  • 그런 다음 개발자 옵션으로 돌아가 USB 디버깅을 켭니다.

허용 팝업이 뜨지 않을 때

케이블을 꽂은 뒤 화면 위쪽 알림을 내려 USB 연결 방식을 "파일 전송"으로 바꿔 보세요. 그래도 뜨지 않으면 개발자 옵션의 USB 디버깅 권한 승인 취소를 누른 뒤 케이블을 뺐다가 다시 꽂습니다.

샤오미 · 레드미 · 포코에서 주의할 점

샤오미 계열은 USB 디버깅만 켜서는 PC에서 화면을 누르거나 글자를 입력할 수 없습니다. 개발자 옵션에서 아래 세 가지를 모두 켜야 합니다.

  • USB 디버깅
  • USB 디버깅(보안 설정) — PC에서 보내는 터치와 입력을 허용하는 항목입니다. 켤 때 경고가 여러 번 나오고, 샤오미 계정 로그인이나 유심 장착을 요구하는 기종이 있습니다.
  • USB를 통해 설치 — PC에서 보조 앱을 설치할 수 있게 하는 항목입니다. 이 매크로는 한글을 입력하기 위한 보조 키보드 앱을 휴대폰에 설치하는데, 이 항목이 꺼져 있으면 설치가 막힙니다.

함께 켜두면 편한 설정

  • 화면 켜짐 상태 유지(개발자 옵션) — 충전 중에는 화면이 꺼지지 않습니다. PC에 꽂아 두고 오래 돌릴 때 유용합니다. 화면이 계속 켜져 있으니 밝기는 낮춰 두세요.
  • 화면 잠금 방식 — PIN이나 패턴이 걸려 있으면 PC에서 잠금을 풀 수 없습니다. 무인으로 돌릴 휴대폰이라면 잠금을 "드래그"나 "없음"으로 바꿔 두는 방법이 있습니다. 평소 들고 다니는 휴대폰이라면 보안이 약해지므로 권하지 않습니다.

보안을 위해 알아둘 점

USB 디버깅이 켜진 휴대폰은 허용한 PC에서 화면을 보고 조작할 수 있습니다. 그래서 다음을 지켜 주세요.

  • "이 컴퓨터에서 항상 허용"은 내 PC에서만 체크합니다. PC방이나 남의 컴퓨터에서는 허용하지 마세요.
  • 공공장소의 USB 충전 포트에 꽂았을 때 허용 팝업이 뜨면 반드시 거부하세요.
  • 더 이상 쓰지 않을 때는 USB 디버깅을 끄고, USB 디버깅 권한 승인 취소로 지금까지 허용한 PC 목록을 지울 수 있습니다.
  • 일부 금융 앱은 USB 디버깅이 켜져 있으면 실행을 막거나 경고를 띄웁니다. 이런 앱을 쓸 때만 잠시 꺼 두면 됩니다.

사진과 함께 따라 하는 기본 순서는 5. 안드로이드 앱 매크로 연결하기에, 켰는데도 연결되지 않을 때의 점검 순서는 휴대폰 연결이 안 될 때에 있습니다.
