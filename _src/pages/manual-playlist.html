8. 재생목록(📃 노래) 사용법

원하는 영상들을 조합해 유튜브 재생목록을 자동으로 만듭니다. 같은 이름의 재생목록이 이미 있으면 새로 만들지 않고, 그 재생목록 안의 영상을 모두 지운 뒤 새 조합으로 다시 채웁니다.

  • 재생목록 이름 / 재생목록 시간 — 만들 재생목록의 이름과, 전체 재생 시간이 몇 시간 분량이 되게 채울지 입력합니다. 시간 단위이고 0.5처럼 소수도 됩니다. 영상을 하나씩 이어 붙이다가 입력한 시간을 넘는 순간 멈추므로 실제 길이는 조금 더 길게 나옵니다.
  • 영상 목록 — 넣고 싶은 영상을 유튜브 주소로 추가합니다. 공유 버튼으로 복사한 youtu.be 짧은 주소도 됩니다.
  • 핵심 체크박스 — 더 자주 나오게 하고 싶은 영상에 표시합니다.
  • 핵심+ 체크박스 — 핵심영상 가운데서도 먼저 뽑히게 하고 싶은 영상에 표시합니다. "핵심"을 켜지 않고 "핵심+"만 켜도 핵심영상으로 취급합니다. 핵심+가 뽑힌 뒤에는 덜 나온 다른 핵심영상에 차례가 돌아가므로 핵심+만 계속 나오지는 않습니다.
  • 핵심영상 패턴 — 핵심영상을 어떤 규칙으로 섞을지 고릅니다. 아래 다섯 가지가 있습니다.
패턴배치 규칙
시간 내 중복 방지같은 영상이 입력한 시간(분, 기본 30분) 안에 다시 나오지 않게만 합니다.
시간+연속 중복 방지위 규칙에 더해 핵심영상 두 개가 바로 이어서 나오지 않게 합니다.
퐁당퐁당핵심영상과 비핵심영상을 1:1로 번갈아 배치합니다.
퐁당당퐁당핵심영상 사이에 비핵심영상이 2개, 1개씩 번갈아 들어갑니다.
퐁당당당퐁당당핵심영상 사이에 비핵심영상이 3개, 2개씩 번갈아 들어갑니다.

패턴별 실제 배치 예시와 고르는 기준은 재생목록 패턴 고르기에 따로 정리했습니다.

기존 영상만 삭제

재생목록 이름과 계정만 입력한 뒤 주황색 기존 영상만 삭제 버튼을 누르면, 그 이름의 재생목록을 새로 만들거나 지우지 않고 안에 있는 영상만 전부 지워 빈 재생목록으로 만듭니다. 영상 목록/시간/패턴 설정은 이 기능에는 쓰이지 않습니다.

알아두면 좋은 점

  • 영상 목록과 설정은 자동으로 저장되어 다음에 그대로 다시 쓸 수 있습니다.
  • 같은 주소를 두 번 넣을 수 없습니다. 삭제되었거나 비공개인 영상은 재생시간을 알 수 없어 실행 전에 오류로 알려 줍니다.
  • 영상 수가 너무 적으면 중복 방지 시간을 지키면서 목표 시간을 채우기 어렵습니다. 30분 규칙이라면 영상 길이를 합쳐 30분은 넘도록 목록을 준비하세요.
  • 끝나면 영상별로 몇 번 들어갔는지와 전체 길이가 로그에 찍힙니다.
