준비물

  • 공통 — Windows PC, 인터넷 연결, 관리자에게 받은 실행 암호.
  • 브랜드평판 / 유튜브 / 재생목록 — PC에 설치된 크롬 브라우저. 그 밖의 준비물은 없습니다.
  • 스타플래닛 / 셀럽챔프 — 실제 안드로이드 휴대폰 앱을 USB로 연결한 PC가 원격으로 조작하는 방식입니다. 휴대폰과 데이터 전송용 USB 케이블이 필요하고, 처음 한 번은 휴대폰의 "USB 디버깅"이라는 개발자 설정을 켜줘야 합니다 (이 문서의 5장에서 사진과 함께 자세히 설명합니다). 아이폰은 지원하지 않습니다.

설명서를 읽는 순서

  1. 2장에서 프로그램을 설치하고 실행 암호를 통과합니다.
  2. 3장과 4장에서 화면 구성을 익히고 계정을 등록합니다.
  3. 휴대폰 앱 기능을 쓸 분은 5장에서 휴대폰을 연결합니다.
  4. 6장부터 10장 가운데 쓰려는 기능의 장만 골라 읽습니다.
  5. 매일 정해진 시간에 돌리고 싶다면 11장을 읽습니다.
알아두세요 한 창에서는 한 번에 한 기능만 실행됩니다. 실행 중에는 휴대폰이나 프로그램이 띄운 크롬 창을 직접 만지지 마세요. 화면이 예상과 달라져 미션이 실패할 수 있습니다.
