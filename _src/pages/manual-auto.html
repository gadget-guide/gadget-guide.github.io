13. 무인 자동 실행 (고급)

실행 파일을 --auto 옵션과 함께 실행하면, 창이 뜨자마자 사람이 아무것도 누르지 않아도 자동으로 매크로를 시작합니다(등록해둔 계정과 체크해둔 카테고리/미션/옵션을 그대로 사용). 이걸 Windows 작업 스케줄러에 등록해두면 정해진 시간에 PC가 알아서 실행하게 만들 수 있습니다.

옵션 뒤에 번호를 붙여 실행할 기능을 고릅니다

인수실행되는 기능
--auto브랜드평판 → 유튜브 (번호를 안 붙였을 때의 기본값)
--auto 1브랜드평판만
--auto 2유튜브만
--auto 3스타플래닛만
--auto 4셀럽챔프만
--auto 5K-탑스타만 (v2.1.5부터)
--auto 6스타덤만 (v2.2.3부터)
--auto 3,4스타플래닛을 끝낸 뒤 셀럽챔프
  • 쉼표로 여러 번호를 이으면 적은 순서대로 하나가 끝난 뒤 다음을 시작합니다(v2.1.0부터). --auto 4,3이면 셀럽챔프를 먼저 합니다. 쉼표 앞뒤에 띄어쓰기를 넣지 마세요.
  • 휴대폰이 여러 대여도 한 작업 안에서는 하나가 끝난 뒤 다음을 시작합니다(v2.2.8부터. v2.2.0~v2.2.7은 빈 휴대폰이 있으면 바로 같이 시작했습니다). 휴대폰 두 대를 동시에 쓰려면 아래처럼 작업을 두 개 만드세요 (5-6 참고).
  • 티켓 탭의 "대기 중 장미 같이 하기"나 "대기 중 스타 같이 하기"를 켜 두었으면 --auto 4,5,6처럼 4번·6번을 같이 적어도 그 앱은 K-탑스타의 광고 대기 시간에만 진행합니다(11장 참고).
  • 스타플래닛과 셀럽챔프는 v2.0.8부터 자동 실행에 포함됩니다. 휴대폰이 USB로 연결되어 있어야 합니다.
  • 재생목록은 자동 실행 대상이 아닙니다.
  • 1~6이 아닌 값을 넣으면 번호를 안 붙인 것으로 보고 브랜드평판 → 유튜브를 실행합니다.
  • 모두 끝나면 로그창 맨 아래에 기능별 결과를 합친 전체 요약이 한 번 더 찍힙니다.
먼저 확인 실행이 끝나도 창이 저절로 닫히지는 않습니다 — 로그에 결과가 남은 채로 계속 떠 있습니다. 브랜드평판과 유튜브를 같은 시간에 따로 돌리고 싶다면 작업을 두 개 만들어 각각 --auto 1, --auto 2로 등록하면 됩니다. 휴대폰이 두 대라면 휴대폰 매크로도 같은 방법으로 --auto 3, --auto 5처럼 작업을 두 개 만드세요(창과 로그가 작업별로 나뉩니다). 휴대폰이 한 대뿐이면 --auto 3,4처럼 한 작업에 이어서 적으세요. 5번(K-탑스타)은 동영상 광고 대기 때문에 몇 시간씩 걸릴 수 있으니 휴대폰이 한 대일 때는 맨 뒤에 두는 편이 좋습니다.

작업마다 K-탑스타 계정 나누기 (v2.2.8부터)

탭 설정은 모든 작업이 같이 쓰기 때문에, 휴대폰 두 대로 작업을 두 개 만들면 티켓 탭의 계정 체크를 작업마다 다르게 할 수 없습니다. 이럴 때는 실행 옵션 뒤에 아래 옵션을 붙이면 그 작업에서만 탭 설정 대신 씁니다. 붙이지 않으면 탭 설정을 그대로 씁니다.

옵션뜻
--ktopstar-accounts 아이디1,아이디2티켓 탭의 사용 체크 대신 적은 계정만 돌립니다. 티켓 탭 계정 목록에 있는 계정이어야 합니다. 카카오톡 계정은 kakao라고 적습니다.
--no-side이 작업에서는 "대기 중 장미/스타 같이 하기"를 하지 않습니다.

예를 들어 휴대폰 1은 스타플래닛을 끝낸 뒤 K-탑스타 계정 하나를, 휴대폰 2는 처음부터 K-탑스타 계정 둘과 셀럽챔프·스타덤을 돌리려면 이렇게 등록합니다.

  • 작업 1: --auto 3,5 --ktopstar-accounts 아이디3 --no-side
  • 작업 2: --auto 5 --ktopstar-accounts 아이디1,아이디2

젤리 탭(스타플래닛)의 "사용할 휴대폰"은 휴대폰 1로 정하고, 작업 1을 작업 2보다 1~2분 먼저 시작하게 등록하세요(예: 작업 1은 0시 0분, 작업 2는 0시 2분). 작업 1이 먼저 휴대폰 1을 잡아 두어야 작업 2의 K-탑스타가 휴대폰 2로 갑니다. 작업 1의 K-탑스타는 스타플래닛이 끝나 휴대폰 1이 비었을 때 시작합니다.

  • K-탑스타 광고 대기는 휴대폰마다 따로라서, 두 휴대폰이 동시에 K-탑스타를 돌리면 광고를 두 배로 볼 수 있습니다.
  • 구글 계정은 두 작업에 같은 아이디를 적지 마세요. 카카오톡 계정은 휴대폰마다 다른 계정이라 kakao는 그 작업이 쓰는 휴대폰에 로그인된 카카오 계정입니다.
  • 티켓 탭의 "사용할 휴대폰"은 자동으로 두세요. 한쪽 휴대폰을 다른 작업이 쓰고 있으면 남은 휴대폰으로 갑니다.

자동 실행 중의 업데이트

새 버전이 나와 있으면 --auto 실행에서는 묻지 않고 바로 업데이트한 뒤, 같은 옵션으로 프로그램을 다시 실행해 이어서 진행합니다. 사람이 없는 시간에 업데이트 창에서 멈춰 있는 일이 없도록 한 동작입니다.

준비: 실행 암호를 먼저 한 번 저장해두기

이 프로그램은 실행할 때마다 실행 암호를 확인합니다. 사람이 없는 새벽 시간에 스케줄이 돌면 그 암호창을 눌러줄 사람이 없어 그대로 멈춰버립니다. 다행히 한 번 암호를 맞게 입력해두면 같은 PC에서는 관리자가 암호를 바꾸기 전까지 다시 묻지 않으므로, 스케줄을 등록하기 전에 그 PC에서 프로그램을 한 번 직접 실행해서 암호를 통과시켜두세요. 이후 무인 실행부터는 암호창 없이 바로 진행됩니다.

Windows 작업 스케줄러 등록하기

  1. 작업 스케줄러를 엽니다
    Windows 검색(또는 Win + R)에서 taskschd.msc를 입력하고 실행합니다.
  2. 오른쪽 "작업 만들기"를 클릭합니다
    ("기본 작업 만들기"보다 세부 설정이 가능한 작업 만들기를 추천합니다.)
  3. 일반 탭 — 이름을 정하고, "사용자가 로그온했는지 여부에 관계없이 실행"을 고를지 정합니다
    로그온 여부와 무관하게 실행하도록 하면 화면이 안 보이는 상태(잠금 화면 등)에서도 돌아가지만, 진행 상황을 눈으로 확인하기는 더 어렵습니다. 처음 설정할 때는 "로그온한 경우에만 실행"으로 두고 화면을 보면서 한 번 테스트해보길 권합니다.
  4. 트리거 탭 — "새로 만들기"로 원하는 시작 시간을 지정합니다
    예: 매일 오전 6시.
  5. 동작 탭 — "새로 만들기" → "프로그램 시작"을 고릅니다
    프로그램/스크립트에는 실행 파일의 전체 경로(예: D:\매크로 폴더 안의 exe 파일)를, 인수 추가에는 --auto(또는 --auto 3,4처럼 원하는 번호)를 입력합니다. 시작 위치(옵션)에는 실행 파일이 들어 있는 폴더 경로를 넣어 두세요.
  6. 저장하고, 등록한 작업을 오른쪽 클릭 → "실행"으로 한 번 테스트합니다
    프로그램이 정말 자동으로 고른 기능부터 시작하는지, 로그창에 진행 상황이 잘 찍히는지 확인하세요.

절전 모드, 화면 잠금, 휴대폰 화면 꺼짐처럼 무인 실행에서 자주 걸리는 부분은 매일 자동으로 돌릴 때 준비에 따로 정리했습니다.
